# Phúc Tâm – Website + Gọi món QR + Quản lý + Bếp

Web tĩnh (HTML/CSS/JS thuần), deploy trên Vercel, dữ liệu realtime bằng Firebase Firestore.
Hướng dẫn triển khai & vận hành: **HUONG-DAN.md**.

## File
- index.html, style.css, site.js – website giới thiệu + đặt bàn
- order.html, order.js – app gọi món của khách (QR)
- dat-hang.html, dat-hang.js – đặt món giao hàng, thanh toán trước
- quan-ly.html, quan-ly.js, ql-menu.js, ql-report.js, ql-bill.js – quản lý, thực đơn, báo cáo, in bill
- bep.html, bep.js – màn hình bếp / phục vụ
- store.js, common.js, menu-data.js, app.css – dùng chung (menu-data.js là thực đơn gốc ban đầu)
- firebase-config.js – cấu hình Firebase
- manifest.json, icon-*.png, *.jpg – icon app, logo, ảnh món
